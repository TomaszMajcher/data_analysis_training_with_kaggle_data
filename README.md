# 🌍 Natural Disasters – Death Toll Analysis

This project analyzes the human impact of natural disasters using historical data.  
It focuses on the **total number of deaths** caused by various disaster types across countries and regions.

---

## 📊 Project Overview

- 🗂️ **Dataset:** `public_emdat_project.csv` (source not specified)
- 📆 **Time Scope:** Includes start and end years for each event
- ⚠️ **Key Metrics:** Total Deaths, Disaster Group, Disaster Type, Country, Region

The goal is to explore which disasters caused the highest death tolls, where they occurred, and which types were the most deadly.

---

## 🛠️ Tools & Technologies

- 🐍 Python
- 📦 Pandas
- 📊 Plotly Express
- 📁 Jupyter Notebook

---

## 🔍 Analysis Includes

- The **most deadly disaster** (highest single-event death toll)
- **Death toll by country**
- **Death toll by region**
- **Death toll by disaster group and type**
- Filtering by disasters with more than **1,000 deaths**
